01Create a learner profile

Calls POST /profile. This creates a real row in the production Postgres database.

02Get the next scenario

Calls GET /scenario. The Adaptive Learning Engine picks a situation from the Knowledge Graph based on the profile above.

Create a profile first.

03Have a conversation

Calls POST /conversation. A live LLM plays the role in this scenario; the Repair Engine checks each message you send.

Try sending no entiendo to see the Repair Engine trigger.

04Readiness score

Calls GET /readiness. Purpose-weighted score computed from this learner's actual turn and repair history, not a fixed number.

Have at least one conversation turn first.
