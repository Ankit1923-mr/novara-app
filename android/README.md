# NOVARA Android

Owner: Sakshi.

Kotlin/Compose app — intake, purpose selection, scenario, conversation/repair UI, readiness dashboard.

Build against `../docs/api-contract.md` using mocked responses until the backend is deployed; then swap the base URL to the real one (see `docs/api-contract.md` → Base URL section).

## Setup

Open this folder in Android Studio and let it initialize a new Kotlin/Compose project here (or `File > New > New Project`, set location to this folder).
